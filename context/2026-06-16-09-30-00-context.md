## Contrato congelado pelos tests

Body do 409 retornado pelo register (caminho: `auth_service.RegisterUser`):
```json
{
  "error": {
    "code": "CONFLICT",
    "message": "email already registered",
    "trace_id": "...",
    "details": []  // só no core
  }
}
```

Frontend trata via `ApiError.code === "CONFLICT"` mostrando CTA.
Mensagem é só fallback (frontend já tem texto próprio).
